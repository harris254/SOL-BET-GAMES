# SOL-BET GAMES — AIDE Build Version

This version includes an AIDE-compatible `gradlew` launcher. In AIDE, open the `SOL-BET-GAMES` folder itself (the folder containing `gradlew` and `settings.gradle`).

## Build
1. Extract this ZIP.
2. In AIDE choose **Open** and select the `SOL-BET-GAMES` folder.
3. Let the project finish indexing/syncing.
4. Press **Run ▶** to build and install the debug APK.
5. If AIDE asks to use Gradle, allow it.

The current app is a prototype: Normal Tips, VIP Tips, automatic local VIP expiry, Results, Account, and a Games/Coming Soon area. Real payment processing and an online admin/backend are not connected yet.
